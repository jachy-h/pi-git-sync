## 进度更新规则

每完成一个任务时：

1. 立即勾选对应项，不批量补记；
2. 在“验证记录”中写入日期、命令和结果；
3. 测试失败或实现不完整时保持阶段为“进行中”，不得标记完成；
4. 行为变更、原计划否决或新增风险必须同步回写 `v0.5-plan.md`；
5. 每个 Phase 结束时记录实际文件变化、coverage、测试数量和剩余风险。
